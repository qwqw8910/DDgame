# 同詞相遇：題目驅動版（`same-word`）規格 v4

> 狀態：v4 已實作（伺服器純邏輯 + socket + 前端），尚未在瀏覽器實機試玩 | 日期：2026-11-03
> 參考：http://samewordgame.hikawa00.top/（同词相遇）、Herd Mentality（從眾牛）、Mind Meld
> 房間：沿用 `server/room`（`registerRoomHandlers`），不修改共用模組

---

## 1. 為什麼從 v3 改成 v4

v3 是「自由聯想 + 第幾輪首次相同決定稱號，未配對者剩 1 人才結束」。推論上的問題：

| 問題 | v4 的處理 |
|---|---|
| 沒有題目，12 人幾乎不可能憑空寫同一個詞 | 每輪一個題目（題庫 `server/same-word/prompts.js`），答案自然集中 |
| 人多時結束條件拖很久，已配對的人沒有目標 | 固定題數（預設 5 題），每題都計分，約 5 分鐘 |
| 只有結算才有回饋 | 每輪揭曉當場加分，書寫與揭曉畫面都有即時分數榜 |
| 揭曉一次全翻、要等房主按鈕 | 逐組翻牌（落單先翻、最大組最後翻）；揭曉後自動倒數進下一輪，房主可跳過 |
| 「與眾不同」是輸家卻當獎項 | 改為「🦄 最特別」小徽章（累計獨一無二次數），不影響勝負 |
| 離譜票是額外負擔 | 改成揭曉時的 emoji 反應（🤣 🤔 👏），不影響計分 |

保留原版精神：終局挑戰（Mind Meld）讓全員合作收斂到同一個詞。

## 2. 規則

### 2.1 一局流程

```
waiting ─開始→ writing ─全員送出／時間到→ revealed ─自動倒數／房主跳過→ writing …
                                                      └ 最後一步 → finished
```

1. **題目輪**（預設 5 題，3–10 可選）：每輪顯示一個題目，所有人同時寫一個詞（預設 30 秒；全員送出就提早揭曉）。
2. **終局挑戰**（可關，預設開）：題目輪結束後，全員合作，看上一輪每人寫的詞，往中間靠攏，寫出同一個詞。最多 3 次，全員同詞即成功並結束。
3. **揭曉**：翻牌後停留 `revealSeconds`（預設 10 秒）自動進下一步；房主可按「下一輪」跳過。
4. 房主可隨時「提前結算」（書寫中的本輪作廢）。

### 2.1.1 接龍模式（`mode: 'chain'`）

大廳可切換的第二個模式（預設仍是題目模式）：

- 固定 6 輪。只有第 1 輪給題目；第 2–6 輪沒有題目，畫面顯示上一輪大家寫的詞當線索，寫一個和它們都有關的新詞。
- 每輪計分與兩兩默契同 §2.3（同詞 k 人各 +(k−1)，6 輪計入默契比例）。
- **前面各輪出現過的詞不能再寫**（含第 1 輪），否則大家一直重複熱門詞就能無限拿分。
- 全員同詞：每人 +3 並**提早結束**（結算顯示「第 N 輪全員同詞通關」）。
- 沒有終局挑戰；`rounds`、`converge` 設定在此模式忽略，大廳自動隱藏。
- 剩不到 2 位在場玩家時結束。

### 2.2 詞的限制與「相同」判定

不變：中文字與英文字母，1–12 字；英文不分大小寫，全形英文轉半形；不支援也不偵測簡體（「蘋果」≠「苹果」）；逾時未送出為空白，空白不等於任何詞。前後端都檢查，伺服器為準。

**v4 題目模式移除**「前幾輪用過的詞不能再寫」：有題目後不再需要，終局更需要重複大家寫過的詞。接龍模式保留此限制。

### 2.3 計分

| 情況 | 分數 |
|---|---|
| 同詞組 k 人（k ≥ 2） | 組內每人 +(k−1) |
| 全員同詞（題目輪，人數 ≥ 2） | 每人再 +3（心電感應） |
| 落單（題目輪，人數 ≥ 3） | 0 分，記一次 🦄（2 人局不計） |
| 終局第 1／2／3 次全員同詞 | 全場各 +6／+4／+2，成功即結束 |
| 終局 3 次都失敗 | 不扣分 |

終局中的部分同詞不計分、不累積兩兩默契。

### 2.4 兩兩默契與結算榜

兩人的默契值 = 題目輪中「寫出相同詞」的題數 ÷ 已揭曉題數（0–100%），稱號門檻（`CHEMISTRY_TIERS`）：

| 比例 | 稱號 |
|---|---|
| ≥ 90% | 💘 天生一對 |
| ≥ 75% | ✨ 心有靈犀 |
| ≥ 60% | 🤝 默契十足 |
| ≥ 45% | 😊 還算合拍 |
| ≥ 30% | 🌱 慢熟型 |
| ≥ 20% | 🔧 需要磨合 |
| ≥ 10% | 😅 勉強同頻 |
| ≥ 1% | 🩹 差點錯過 |
| 0% | 💔 死對頭 |

結算榜：🏆 默契王（最高分，可並列）、🎯 終局結果、📊 分數榜、💘 最佳拍檔（比例最高且 > 0，最多 3 組）、💔 頭號死對頭（比例最低，需有高低差，2 人局不列，依雙方總同詞數再固定雜湊排序）、🦄 最特別（獨一無二最多次）、🤣 離譜王（收到最多 🤣）、🤝 個人默契指數（與所有人比例平均）、N×N 熱力圖。同分排序用固定雜湊，結果可重現。

### 2.5 表情反應

揭曉階段每人可對「別人的詞」貼一個 emoji（🤣 🤔 👏），可換、可收回，不能對自己、空白或已離場者。只下發每張卡收到的個數，不公開是誰貼的。不影響計分，🤣 用來頒離譜王。

### 2.6 設定（`options`）

| 選項 | 值 | 預設 |
|---|---|---|
| `mode` | `prompts` / `chain` | `prompts` |
| `rounds` | 3–10 題（僅題目模式） | 5 |
| `timerSeconds` | 15–180 | 30 |
| `converge` | true / false（僅題目模式） | true |
| `revealSeconds` | 5–60 | 10（大廳 UI 未開放，可由伺服器調整） |

玩家數 2–12。房間模組不保存建房 options，由房主進房後用 `sw:set-options` 設定。

### 2.7 邊界

- 中途離開：之後的輪次排除，已得分數與已成立的同詞保留（不進結算榜）；剩不到 2 人回到大廳；終局需要 ≥ 2 位在場玩家，否則跳過。
- 斷線：座位保留，逾時視為空白，重連後還原階段、倒數與自己已送出的詞。
- 遊戲中新加入者為觀戰者，結束後可升格。

## 3. 架構

```
server/same-word/
  gameLogic.js        純函式：createGame / startGame / submitWord / settleRound / react / nextRound / finishNow / leavePlayer / buildResult / buildView
  gameLogic.test.js   node --test（單元）
  prompts.js          題庫（60 題）
  index.js            registerNamespace：房間 hooks + sw:* 事件 + 書寫倒數／揭曉自動前進計時器
  same-word.integration.test.js
vue-app/src/apps/same-word/
  pages/              SameWordLobbyPage / SameWordRoomPage
  components/         SwPrompt（題目／終局線索）、SwWriteBox、SwRevealBoard（逐組翻牌＋反應）、SwScoreboard、SwResultBoard、SwPairMatrix
  composables/useSameWord.js
  data/constants.js
```

### Socket 事件（namespace `/same-word`）

| 方向 | 事件 | Payload |
|---|---|---|
| C→S | `sw:set-options` | `{ options }`（房主、大廳） |
| C→S | `sw:start` / `sw:finish-now` / `sw:restart` / `sw:next-round` | 僅房主；`next-round` 僅揭曉階段，等同跳過倒數 |
| C→S | `sw:submit` | `{ word }`（writing 可覆蓋） |
| C→S | `sw:react` | `{ targetId, emoji }`（revealed；`emoji: null` 收回） |
| S→C | `sw:state` | 每人專屬視圖 |
| S→C | `sw:error` / `sw:notice` | — |

### 資訊隱藏

- `writing`：只下發 `submitted`（誰已送出）與自己的詞；不下發送出時間、別人的詞、未來的題目。
- `revealed` 後才下發該輪 `words`；反應只下發個數。

## 4. 待辦與已知限制

- 尚未瀏覽器實機試玩；逐組翻牌節奏、揭曉停留秒數、各題的同詞機率需實測後調整。
- 題庫 60 題為初版，需試玩後汰換太開放或太冷門的題目；是否開放玩家自訂題目未定。
- `docs/same-word-ui-assets-animation.md`、`docs/same-word-image-prompts.md` 仍是 v3 敘述（稱號與「與眾不同」），素材檔仍可沿用；音效與動畫細節待對照 v4 更新。
- 若要重做平衡：用 `game-designer` skill 寫模擬，調整終局分數與全員同詞加成。
