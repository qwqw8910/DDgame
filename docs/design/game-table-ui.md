# 山中別館殺人事件(暫名)— 牌桌 UI 設計

> 對應文件:[game-background.md](game-background.md)(規則與背景)
> 範圍:MVP(Level 1–2,3–6 人,私人房間)

## 一、設計原則

**桌面佈局對所有人一致,只有「隱藏資訊」因人而異。**
伺服器只把玩家有權看的內容傳給該客戶端,他人角色牌永不傳到前端。

- 地點是主角,玩家頭像附著在地點上(投票對象是地點)。
- 自己的地點固定在畫面下方(座位旋轉),其他人依序排在周圍。
- 客房、鍋爐室固定在中央。
- 「誰傳給誰」是公開動作,「牌的內容」是私密資訊。

## 三、每個人看到的差異

| 項目 | 自己 | 別人 | 客房 / 鍋爐室 |
| --- | --- | --- | --- |
| 角色牌 | 可偷看(按住顯示,放開蓋回) | 一律牌背 | 牌背;鍋爐室結算前為空 |
| 抽到的 2 張牌 | 僅抽牌者本人可見 | 只看到「小明正在看牌…」 | — |
| 傳牌動畫 | 看得到牌背從誰飛向誰 | 同左 | — |
| 目擊情報 | 語音口說,畫面不顯示 | 同左 | — |
| 殺人魔 / 共犯 | 看得到自己的角色(是否互認待定) | 不可見 | — |
| 投票 | 自己的票全員投完前隱藏 | 只看到「已投 / 未投」 | — |

## 四、各階段畫面

### 傳牌階段
- 輪到我:我的區域浮出 2 張牌 → 選「留下這張」→ 選「傳給誰」(僅尚無角色的地點可點,其餘變灰)。
- 沒輪到:顯示「等待中」,中央以動畫呈現牌背在誰之間流動。
- 最後一位:兩張牌一張自留、一張放進客房(客房高亮)。

### 討論階段
- 主體為大計時器。
- 提供「我的備忘」小面板(僅自己可見),記錄「誰說他看到什麼」,降低記憶負擔。不是聊天,不違反 MVP 範圍。

### 投票階段
- 點地點卡投票,確認後蓋上投票牌。
- 他人僅顯示「已投」狀態。

### 結算階段
1. 依序翻開得票最高地點的牌,移入鍋爐室。
2. 顯示勝負與原因。
3. 進入**真相回放**:時間軸列出每次傳牌「誰看到什麼、留了什麼、傳給誰、口頭說了什麼」。這是唯一全員可看見所有牌的時刻。

## 五、實作注意事項

1. **座位旋轉**:每個客戶端各自重排,房間狀態中的座位順序不變。
2. **防窺機制**:偷看牌用「按住顯示、放開蓋回」,避免螢幕分享時洩漏。
3. **抽牌是私密事件**:伺服器只推送給該玩家,其他人只收到「某人抽了牌」事件。
4. **少人局**:3 人局地點取 3 + 中央 2,環繞排法需自動調整。
5. **手機直式**:地點改 2 欄格狀,「我的區域」做成底部抽屜。
