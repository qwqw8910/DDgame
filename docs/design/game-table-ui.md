# 山中別館殺人事件(暫名)— 牌桌 UI 設計

> 對應文件:[game-background.md](game-background.md)(規則與背景)
> 範圍:MVP(Level 1–2,3–6 人,私人房間)
> 版本:v2(2026-10-05)— 改為「滿版、不捲動」的 4×2 場地盤面;取代舊版「環繞座位 + 中央客房鍋爐」

## 一、設計原則

**桌面佈局對所有人一致,只有「隱藏資訊」因人而異。**
伺服器只把玩家有權看的內容傳給該客戶端,他人角色牌永不傳到前端。

- 地點是主角,玩家頭像附著在地點上(投票對象是地點)。
- **遊戲進行中的畫面必須「滿版、不捲動」**:整個牌桌固定在視窗(`100dvh × 100vw`)內,依螢幕大小等比縮放,不出現頁面捲軸(上下、左右皆無)。
- 場地盤面固定為 **4 欄 × 2 列 = 8 格**,所有人看到的位置相同(不再做座位旋轉)。
- 客房、鍋爐室固定佔盤面最後兩格(右下角),不再放中央。
- 自己的操作區固定在最右邊(手機為底部)。
- 「誰傳給誰」是公開動作,「牌的內容」是私密資訊。

```

├──────────────────────────┤

│ │地點5│地點6│客房 │鍋爐 ││     4×2 維持不變,卡片改精簡版
│ └─────┴─────┴─────┴─────┘│
├──────────────────────────┤
│ 我的操作區(底部固定面板)  │  ← 約 35–40dvh,內部可捲動
```

- 手機仍維持 4×2:360px 寬每格約 80px,足夠放「地點名 + 玩家暱稱 + 小牌背」。
- 手機橫向視為桌機版型(左盤面、右操作區),高度不夠時卡片自動縮小而非捲動。
- 備忘錄(📝)為浮動按鈕開啟的抽屜,不佔版面。

## 三、場地盤面(4 × 2)

### 3.1 格位規則

| 格位 | 內容 |
| --- | --- |
| 第 1–6 格 | 玩家地點(含**自己的地點**,以邊框 / 色彩強調為「我」) |
| 第 7 格 | 客房 |
| 第 8 格 | 鍋爐室 |

- 順序:依房間座位順序由左至右、由上而下填入第 1–6 格,所有客戶端相同。
- **少人局**:3–5 人時,第 1–6 格只放實際有人的地點,**空位不顯示地點**(留白或淡色佔位),客房與鍋爐室**仍固定在第 7、8 格**,位置不隨人數變動。
  > 待確認:少人局多出來的地點牌是否仍要顯示?目前假設「不顯示」,見第七章。
- 自己的地點同時出現在盤面(供點選投票 / 接收傳牌)與右側操作區(顯示角色牌與操作)。

### 3.2 單格內容(`LodgeSeat`)

- 地點圖(上)、地點名、玩家暱稱、角色牌背 / 空位標示、狀態徽章(輪到中、已投、得票數、鍋爐)。
- 客房格:牌背;結算前不顯示內容。
- 鍋爐室格:結算前為空;結算後依序翻入得票最高地點的角色牌。
- 三種尺寸隨格寬自動切換(見 4.3):完整 / 精簡 / 極簡。

## 四、滿版與響應式規則(取代「拉霸」問題)

### 4.1 根容器

- 根容器 `h-[100dvh] w-full overflow-hidden`(用 `dvh`,避免手機網址列造成 100vh 溢出)。
- 內部 `flex flex-col`:頂欄固定高,其餘 `flex-1 min-h-0`(**`min-h-0` 必加**,否則子元素撐破父層又出現捲軸)。
- 加上 `env(safe-area-inset-*)` padding,避開 iPhone 瀏海與底部橫條。
- 只在「遊戲進行中」的牌桌套用 `overflow-hidden`;大廳、結算回放維持可捲動(見 4.4)。

### 4.2 盤面格線

- 盤面容器:`grid grid-cols-4 grid-rows-2 gap-[clamp(4px,1vw,12px)] h-full w-full`。
- 每格 `min-w-0 min-h-0`,內容以**容器相對單位**縮放(`@container` + `cqw` / `cqh` 或 `clamp()`),不用固定 px 高度。
- 地點圖用 `object-cover` 填滿格子剩餘空間,不設固定 `aspect-ratio`,讓高度吃滿而非撐高。

### 4.3 尺寸分級(依格子實際寬度,container query)

| 格寬 | 版型 | 顯示內容 |
| --- | --- | --- |
| ≥ 160px | 完整 | 地點圖 + 地點名 + 暱稱 + 牌背 + 徽章文字 |
| 90–160px | 精簡 | 地點圖 + 地點名 + 暱稱(縮字)+ 小牌背,徽章只留圖示 |
| < 90px | 極簡 | 地點圖當背景 + 暱稱疊在底部,狀態以角標圖示表示;點格後以底部彈出卡顯示詳情 |

### 4.4 各區塊的「不捲動」例外

| 區域 | 捲動策略 |
| --- | --- |
| 場地盤面 | 永不捲動,只縮放 |
| 頂欄 | 永不捲動;窄螢幕時次要資訊收進 ⋯ 選單 |
| 我的操作區 | 內容超出時**僅此區內部**捲動(`overflow-y-auto`),不影響整頁 |
| 大廳、等待室 | 可整頁捲動 |
| 結算「真相回放」 | 以全螢幕面板 / 抽屜開啟,面板內部捲動;關閉後回到不捲動的盤面 |
| 開票階段「投票明細」 | 放進我的操作區(或彈出面板),不再插在盤面下方撐高頁面 |

### 4.5 斷點與驗證清單

斷點:`< 640px` 手機直式、`640–1023px` 平板 / 手機橫向、`≥ 1024px` 桌機。

| 驗證裝置 | 解析度 | 預期 |
| --- | --- | --- |
| iPhone SE | 375 × 667 | 盤面 4×2 極簡 / 精簡,操作區底部,無捲軸 |
| iPhone 14 | 390 × 844 | 同上,格子較大 |
| 手機橫向 | 844 × 390 | 左盤面右操作區,卡片縮小,無捲軸 |
| iPad 直 / 橫 | 768 × 1024 / 1024 × 768 | 直式用手機版型、橫式用桌機版型 |
| 筆電 | 1366 × 768 | 桌機版型,無捲軸 |
| 桌機 | 1920 × 1080 | 桌機版型,盤面放大不留大片空白 |

另測:瀏覽器縮放 125% / 150%、手機網址列收合前後、6 人與 3 人局。

## 五、每個人看到的差異

| 項目 | 自己 | 別人 | 客房 / 鍋爐室 |
| --- | --- | --- | --- |
| 角色牌 | 可偷看(按住顯示,放開蓋回) | 一律牌背 | 牌背;鍋爐室結算前為空 |
| 抽到的 2 張牌 | 僅抽牌者本人可見 | 只看到「小明正在看牌…」 | — |
| 傳牌動畫 | 看得到牌背從誰飛向誰 | 同左 | — |
| 目擊情報 | 語音口說,畫面不顯示 | 同左 | — |
| 殺人魔 / 共犯 | 看得到自己的角色(是否互認待定) | 不可見 | — |
| 投票 | 自己的票全員投完前隱藏 | 只看到「已投 / 未投」 | — |

## 六、各階段畫面

### 傳牌階段
- 輪到我:操作區浮出 2 張牌 → 選「留下這張」→ 點盤面上「傳給誰」(僅尚無角色的地點可點,其餘變灰)。
- **牌面來源標示**(下一家必須分辨哪張是上一家傳來的):
  - 收到的牌標示「來自 玩家X」(X 為上一位傳牌者的暱稱)。
  - 自己從牌堆抽的牌標示「剛抽到」。
  - 第一位玩家兩張牌皆從牌堆抽,兩張都標「剛抽到」。
  - 最後一位玩家同樣適用:收到的牌標「來自 玩家X」,抽的牌標「剛抽到」,再選一張自留、一張放進客房。
  - 來源標示只代表「誰傳的」(公開資訊),不代表內容可信,因為口頭目擊情報可以說謊。
  - 伺服器在手牌資料中附帶 `from`(`'passed'` 或 `'deck'`)與 `fromPlayerId`(傳牌者 id;牌堆抽的為 `null`),前端不自行推斷。
- 沒輪到:操作區顯示「等待中」,盤面上以動畫呈現牌背在格子之間流動。
- 最後一位:兩張牌一張自留、一張放進客房(第 7 格客房高亮)。
- 閱牌鎖定秒數、確認按鈕等沿用現行邏輯。

### 討論階段
- 頂欄計時器放大強調(桌機);手機以頂欄單行計時器為主。
- 「我的備忘」維持浮動按鈕開啟的抽屜(僅自己可見),記錄「誰說他看到什麼」。不是聊天,不違反 MVP 範圍。

### 投票階段
- 點盤面上的地點格投票(可投自己的地點),確認後蓋上投票牌;確認按鈕在操作區。
- 他人僅顯示「已投」狀態。

### 開票階段
- 票全部公開,律師 / 富商公開動作即時顯示於彈窗(沿用現行 `LodgeRevealModal`)。
- 投票明細移入操作區,內部捲動。

### 結算階段
1. 依序翻開得票最高地點的牌,移入第 8 格鍋爐室。
2. 顯示勝負與原因(橫幅覆蓋於盤面上方或操作區頂部,不推擠盤面)。
3. 進入**真相回放**:全螢幕面板,時間軸列出每次傳牌「誰看到什麼、留了什麼、傳給誰、口頭說了什麼」。這是唯一全員可看見所有牌的時刻。

## 七、實作注意事項

1. **不再做座位旋轉**:盤面順序所有客戶端一致,只有「我」的格子用強調樣式標出。
2. **防窺機制**:偷看牌用「按住顯示、放開蓋回」,避免螢幕分享時洩漏。
3. **抽牌是私密事件**:伺服器只推送給該玩家,其他人只收到「某人抽了牌」事件。
4. **現行程式需調整**:[MountainLodgeRoomPage.vue](../../vue-app/src/apps/mountain-lodge/pages/MountainLodgeRoomPage.vue) 目前根節點為 `h-[100dvh] overflow-y-auto`,`<main>` 為 `max-w-6xl` 的可捲動欄位;盤面為「其他玩家 3 欄」+「客房/鍋爐 2 欄置中」,自己的地點只在右側面板。需改為 4×2 單一盤面、根節點 `overflow-hidden`,並讓 [LodgeSeat.vue](../../vue-app/src/apps/mountain-lodge/components/LodgeSeat.vue) 與 [LodgeCard.vue](../../vue-app/src/apps/mountain-lodge/components/LodgeCard.vue) 支援三種尺寸。
5. **客房 / 鍋爐室元件化**:鍋爐室目前是頁面內的行內區塊,需抽成與 `LodgeSeat` 同尺寸規格的元件,才能放進格線並隨格寬縮放。
6. **等比縮放優先**:使用 container query / `clamp()`,避免用大量斷點寫死像素。
7. **觸控**:所有可點元素最小 44×44px 觸控區(極簡格以整格為點擊區);不依賴 hover。
