# Spec: 晚餐邀請與食物選擇器 (Dinner Invite)

## Objective

**我們在建造什麼：** 一個惡搞趣味的單頁晚餐邀請 SPA，讓使用者能以惡搞互動方式邀請朋友吃晚餐，並一起選擇食物類別與品項。

**使用者旅程：**
1. 收到帶 `?name=小明` 的邀請連結 → 看到邀請頁
2. 嘗試拒絕時按鈕逃跑 → 被迫同意（或直接同意）
3. 選擇想吃的大類別 → 選擇具體食物（或盲選轉盤）
4. 看到「晚餐通行證」結果卡 → 複製文字 / 生成下一份邀請連結

**成功標準：**
- [ ] 從任何 `?name=xxx` 連結進入，顯示正確的名稱
- [ ] 拒絕按鈕在 mouseenter/touchstart 時逃跑
- [ ] 觸發 5 次逃跑後，顯示彩蛋提示並隱藏拒絕按鈕
- [ ] 點擊同意後，正確展示 5 大類別卡片
- [ ] 點選類別後展開對應食物清單
- [ ] 盲選：3 秒滾動後隨機停止
- [ ] 結果頁顯示通行證卡片，一鍵複製訊息成功
- [ ] 可輸入新名字並產生 & 複製邀請連結

---

## Tech Stack

- **框架：** Vue 3 (Composition API, `<script setup>`)
- **路由：** vue-router 4（hash mode，現有設定）
- **樣式：** 專案現有 CSS 自訂變數（`--neon-rose`, `--bg-card`, 等）+ `<style scoped>` 動畫
- **動效：** 原生 CSS Transition / Animation（無外部動畫庫）
- **不新增外部依賴**

> **關於 Tailwind CSS：** 本規格決定使用專案現有 inline styles 系統（與其他所有頁面保持一致），以避免安裝 Tailwind preflight CSS reset 破壞現有頁面。視覺效果與 Tailwind 相當。

## Feature Spec

### 階段 1：邀請互動

| 項目 | 規格 |
|---|---|
| 讀 URL | `new URLSearchParams(window.location.search).get('name')` + `decodeURIComponent` |
| 顯示文字 | 有名稱：「嗨，[name]！今晚想跟我一起吃晚餐嗎？🥺」|
| 預設 | 「嗨，神秘嘉賓！今晚想跟我一起吃晚餐嗎？🥺」|
| 拒絕按鈕逃跑 | `mouseenter` + `touchstart` → `position:absolute` + 隨機 `top/left` `(10~80%)`|
| 逃跑動畫 | `transition: all 0.2s ease` |
| 彩蛋閾值 | 5 次觸發後，顯示幽默提示，拒絕按鈕消失 |

### 階段 2：食物選擇

**大類別（5張卡片）：**

| ID | 名稱 | Icon |
|---|---|---|
| noodle | 麵食類 | 🍜 |
| rice | 飯食類 | 🍚 |
| hotpot | 鍋物/湯品類 | 🍲 |
| foreign | 異國料理類 | 🌏 |
| light | 輕食/小吃類 | 🥗 |

**詳細品項：**

```js
{
  noodle: ['牛肉麵','陽春麵','拉麵','烏龍麵','越南河粉','義大利麵','炸醬麵','肉燥乾麵','涼麵','炒泡麵'],
```

**盲選機制：**
- 按鈕：「🎰 幫我盲選 / 我都想吃」
- 效果：快速滾動文字（slot machine），每 80ms 更換顯示品項
- 3 秒後隨機停止，直接進入結果頁

### 階段 3：結果頁

- 顯示「晚餐通行證」卡片 
- 一鍵複製：「我同意跟你一起吃晚餐了！我想吃 [食物]。不准賴皮，今晚見！」
- 邀請連結產生器：輸入新名字 → 產生 `https://domain/#/dinner-invite?name=xxx`

## Testing Strategy

本功能為純前端互動，無後端依賴：

- **手動測試清單（每次調整後執行）：**
  1. `?name=小明` 解碼正確顯示
  2. 拒絕按鈕 hover 逃跑
  3. 5 次後彩蛋觸發
  4. 同意 → 類別選擇正確切換
  5. 類別點選 → 展開品項
  6. 盲選 3 秒後停止
  7. 結果複製文字到剪貼簿成功
  8. 邀請連結產生並複製成功

---

## Boundaries

- **Always：** 使用現有 CSS 設計系統變數；程式碼 `<script setup>` Composition API；`decodeURIComponent` 處理中文名稱
- **Ask first：** 新增 npm 依賴；修改 vite.config.js；修改 style.css
- **Never：** 破壞現有路由與頁面；存取使用者隱私資料；commit 任何 secret
